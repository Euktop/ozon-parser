# Security Policy

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| 0.4.x  | ✅        |
| < 0.4  | ❌        |

## Как сообщить об уязвимости

**Не открывайте публичный issue** для проблем безопасности. Используйте:

- **GitHub Security Advisory** — вкладка **Security** → **Report a vulnerability**
  (приватно, видно только мейнтейнеру).
- **Email** — `<укажите контактный email>` (замените placeholder перед публикацией).

Опишите шаги воспроизведения, версию и потенциальный impact. Ответ — в
течение 7 дней.

## Что считается уязвимостью

- **CORS на `serve`.** Локальный HTTP API доступен без auth (by design —
  защита через CORS). Если нашли способ обойти `Access-Control-Allow-Origin`
  и заставить браузер пользователя выполнить запрос — это уязвимость.
- **Native Messaging host.** `allowed_origins` в `com.ozon_parser.json`
  зафиксирован на extension ID. Если нашли способ запустить host от
  чужого extension ID (или зарегистрировать host без явного действия
  пользователя) — это уязвимость.
- **Installer.** Установка user-level (без UAC). Если найден способ
  эскалации привилегий через `[Run]` или `[Files]` — присылайте.
- **Утечка `*.pem`.** Приватный ключ extension не должен попадать в
  публичный репозиторий/артефакты. Если нашли — сообщите приватно
  (даже если это старая версия — у пользователей может остаться тот же
  ID).

## Известные ограничения (не уязвимости)

- Локальный HTTP API (`serve --host 127.0.0.1`) не требует аутентификации.
  Любой локальный процесс может читать/писать коллекцию. Запуск
  `serve --host 0.0.0.0` — на ваш риск (по умолчанию — `127.0.0.1`).
- `native register` пишет в HKCU (Windows) / `~/.config` (Linux) /
  `~/Library/LaunchAgents` (macOS) — user-level, без UAC/sudo.
- Extension имеет `host_permissions` на `https://www.ozon.ru/*` и
  `http://127.0.0.1/*` — это необходимо для работы. Другие сайты
  недоступны.
- `raw_html` (сырой HTML PDP) хранится в SQLite без шифрования. Если
  коллекция содержит чувствительные данные — шифруйте диск (BitLocker/
  FileVault/LUKS).
