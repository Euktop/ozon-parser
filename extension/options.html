Ozon Parser

Отправляет текущую Ozon PDP в локальное Python-ядро ozon-parser через Native Messaging. Фоновый сервер не нужен.

Нужен только если запущен ozon-parser serve (для bookmarklet / Web UI). Native работает без порта.

Отправляет HTML при заходе на /product/.... Дебаунс 3 с, дедуп 60 с.

Только для активной вкладки. Если ты в другой вкладке — badge обновится, уведомления не будет.

Dev (для разработки):

Показывает dev-действия. Не влияет на ingest.

Перезапускает native host и расширение — нужно после правки Python-кода, чтобы новый код подхватился без переустановки.

Как пользоваться:

  1. Открыть Ozon PDP
  2. Нажать Alt+Shift+O, кликнуть на иконку, или правой кнопкой → «→ Ozon Parser»
  3. Клик на иконку «O» — popup со списком, скачивание, удаление
  4. Auto-ingest (галочка выше) — товары добавляются сами при заходе на PDP
