# Установка Ozon Parser (Windows)

## Что нужно
- Windows 10/11
- Браузер: Chrome, Яндекс.Браузер или Edge

## Установка

1. Скачай `ozon-parser-setup.exe` из [Releases](https://github.com/Euktop/ozon-parser/releases/latest).
2. Двойной клик → «Установить». **Права администратора не нужны.**
3. В конце установки откроется проводник с папкой `extension` и браузер. В окне установщика будет инструкция.
4. В браузере перейди на `chrome://extensions` (или `browser://extensions` в Яндексе).
5. Включи **«Режим разработчика»** (тумблер справа сверху).
6. Нажми **«Загрузить распакованное»** (Load unpacked) и выбери папку, которая уже открыта в проводнике.
7. Иконка «O» появится на тулбаре.

## Как пользоваться

### Одна страница
1. Открой любой товар на Ozon.
2. Клик на иконку «O» → «Ingest текущей».
3. Товар в коллекции.

### Массовая загрузка
1. Клик на иконку «O» → «Импорт по ссылкам».
2. Вставь список ссылок (по одной на строку).
3. «Запустить» → через 5–10 секунд все товары в коллекции.

### Собрать ссылки со страницы Ozon
1. Открой категорию/поиск на Ozon, пролистай вниз.
2. Иконка «O» → «Собрать ссылки» → попадёшь в «Импорт по ссылкам» с заполненным списком.
3. «Запустить».

### Выгрузка
- **«Копировать MD»** — вставить в DeepSeek/ChatGPT/заметки.
- **MD / JSONL / CSV** — скачать файл.

## Если что-то не работает

### Иконки «O» нет
1. Открой `chrome://extensions` (или `browser://extensions` в Яндексе).
2. Найди «Ozon Parser» в списке. Включи, если выключен.
3. Если нет: включи «Режим разработчика» (тумблер сверху) → «Загрузить распакованное» → выбери папку `%LOCALAPPDATA%\ozon-parser\extension\`.

### Внимание: не запускайте `build/gen_extension_key.py`

Если вы разбираетесь в проекте и наткнулись на `build/gen_extension_key.py` — **не запускайте его**. ID расширения уже захардкожен в `ozon_parser/native/_extension_id.py` и в `manifest.json` (поле `key`). Запуск скрипта создаст **новый** ключ и сломает совместимость с текущим расширением: Chrome откажется запускать native host, потому что `allowed_origins` не совпадут.

### «Cannot connect to native host»
1. Win+R → `cmd` → Enter.
2. Выполни: `"%LOCALAPPDATA%\ozon-parser\ozon-parser.exe" native register`.
3. Перезапусти браузер.

### Появилась капча
Если Ozon просит капчу — расширение откроет вкладку, ты её решишь, парсинг продолжится автоматически (ждём до 2 минут).

## Удаление

Win+R → `appwiz.cpl` → найди «Ozon Parser» → Удалить.

Регистрация native host и ForceList очистятся автоматически.
